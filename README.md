# LifeTrack – Health & Wellness Tracking System

## Project Description

LifeTrack is a health and wellness tracking web application that helps users keep track of their daily health habits and progress. Users will be able to track things such as workouts, water intake, sleep, nutrition, and personal wellness goals.

The goal of this project is to create a simple and easy-to-use system where users can manage their health information and view their progress over time.

## Features

The planned features for LifeTrack include:

- Create a user account
- Login to an existing account
- Track workouts
- Track water intake
- Track sleep
- Track nutrition
- Create personal goals
- View daily and weekly progress
- View previous records
- View charts and trends

## Sprint 1

For Sprint 1, our main goal was to build the basic user account system and create the starting point for the application.

Completed features:

- Create Account page
- User registration
- Login page
- Login validation
- Password validation
- SQLite database for storing users
- Basic welcome/dashboard page

## How to Run the Project

1. Clone or download the project from GitHub.
2. Open the project folder in VS Code.
3. Make sure Python and Flask are installed.
4. Run the application:

```bash
python app.py
```
